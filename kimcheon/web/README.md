# 김천 100산 완등 인증 앱 · 특화제안 웹 목업

Flutter 대신 **React(Vite) 웹**으로 만든 앱 UI 시안입니다. 폰 프레임 안에 앱이 바로 렌더링되며, 수정 후 저장하면 즉시 반영됩니다.

## 실행

```bash
cd kimcheon/web
npm install
npm run dev        # http://localhost:5190
npm run build      # dist/ → 정적 호스팅(상대경로)
```

화면 폭 500px 미만(실제 폰)에서는 프레임 없이 앱만 전체화면으로 표시됩니다.

## 특화제안 3종

| No. | 기능 | 화면 |
|---|---|---|
| 1 | 오삼이와 함께하는 디지털 산행여권 | 산행여권 탭 (권역별 스탬프, 5·10·30·50·100산 배지, 권역·관광 배지) |
| 2 | 나만의 김천 완등 인증카드 | 인증 결과 → 인증카드 (Canvas 합성 3종 디자인, 공유 시트·Web Share·이미지 저장) |
| 3 | 김천 100산 × 지역관광 연계 미션 | 관광미션 탭 / 미션 상세 / 관광지 위치 체크인 → 관광 스탬프(우표형, 장소별 그림) |

## 화면 구성

| No. | 주소 | 화면 |
|---|---|---|
| 1 | `?start=...` | 사용자 앱 (폰 목업) — 로그인 전 상태는 스플래시 → 본인인증(휴대폰·아이핀) → 권한 안내 |
| 2 | `?view=admin` | 관리자 페이지 — 노트북 목업(1440×900) 안에서 실행, 화면 폭 1100px 미만이면 목업 없이 표시 |

## 시작 상태 (`?start=`)

| 버튼 | 값 | 상태 |
|---|---|---|
| 로그인 전 | `empty` | 스플래시 → 본인인증 → 권한 안내 → 인증 0산 홈 |
| 9산 진행 (기본) | `sample` | 9산 인증, 10산 배지 직전 → 황악산 인증 시연 |
| 30산 달성 | `thirty` | 30산 인증, 스탬프·배지 채워진 상태 |

## 데이터

- **산 100개 (실데이터)**: `src/data/peaks.json` — `docs/gimcheon_peaks_research.json`에서 생성. 2020 재지정 목록 확인분 98개 + 2021~2026 인증 기록에 등장하는 봉우리 2개(사발봉 577m·갈비봉 369m).
  목록·높이·산줄기 = 매일신문 「김천의 100산 100설」(2020), 정상 좌표 = OpenStreetMap(ODbL). 좌표 없는 27개는 "인증지점 등록 예정".
- **관광지·음식·숙박 17곳 (실제 장소)**: `src/data/index.ts` `places` — 좌표는 근사치. 착수 시 김천 문화관광 누리집 / TourAPI로 교체.
- **산 사진**: 황악산·금오산만 공공누리 사진, 나머지는 일러스트.
- **오삼이**: 김천시 공식 SNS 캐릭터(수도산 반달가슴곰). 김천시 누리집 > 오삼이 캐릭터 다운로드의 AI(벡터) 파일을 투명 PNG로 변환 → `public/osam/` (기본·인사·엄지척·OK·하트·알림·관광·자두·포도 9종)
- 사용자 인증기록·피드는 샘플.

## 구조

```
src/
  Frame.tsx        폰 프레임 + 안내 패널
  store.ts         상태(zustand) · 배지/미션 계산
  data/            산·권역·배지·관광지·미션 데이터
  lib/card.ts      인증카드 Canvas 합성
  components/      스탬프·배지·캐릭터(art), 지도(MapView), 공통 UI
  app/             화면 (Home, Mountains, MountainDetail, Certify, Result, CardMaker, Passport, Missions, PlaceDetail, My)
```

## 제안서용 화면 캡처

```bash
npm run dev                      # 개발 서버 실행 후
npm i -D playwright && npx playwright install chromium   # 최초 1회
node tools/capture.mjs           # → kimcheon/capture/ 에 저장
```

- 주소에 `?capture=1`을 붙이면 시연용 조작 요소(시연 상황 버튼, 시연용 전환 버튼 등)가 숨겨지고 시계가 9:41로 고정됩니다.
- 결과: 앱 폰목업 · 앱 화면만 · 관리자 노트북목업 · 관리자 전체화면 · 인증카드 원본 · 관리자 모바일, 그리고 `캡처목록.md`(화면 설명 · 관련 요구사항)
