# 울산항 정보공유 AI 서비스 UI 프로토타입

「울산항 정보공유 AI 서비스 구축 PoC 용역」 제안요청서 기준 화면 UI. 백엔드 없이 목업 데이터(`src/mock`)로 동작합니다.

```bash
npm install
npm run dev      # http://localhost:5173
```

제안·심사 때 **"RFP의 과제를 화면으로 어떻게 해결하는지"**를 보여주기 위한 화면입니다.

- `/` **제안 개요**: 발주처 과제(RFP 추진배경) → 해결 방식 → 확인할 화면 → 요구사항 ID, 화면 구성, 요구사항 반영 현황, 기대효과 연결을 한 장에 정리
- `/entry` **진입 경로**: 대표홈페이지(챗봇 버튼, 비로그인) · PortWise(AI 서비스 메뉴, SSO) · 공사 업무망(관리자 콘솔) 접속 구조, 진입 화면 목업, 로그인 상태별 이용 범위, 단계적 오픈
- **진입 모드**: 이용자 앱 URL에 `?via=home`(비로그인) 또는 `?via=portwise`(SSO, 기본값)를 붙여 전환. 비로그인이면 스케줄 예측·서식 메뉴가 잠기고 로그인 안내가 표시됩니다. 사이드바 하단 카드에서도 전환 가능
- **제안 포인트 모드**: 앱 상단의 `제안 포인트` 토글. 켜면 화면 요소에 번호가 붙고 오른쪽 패널에 "과제 · 해결 · RFP 근거"가 표시됩니다. 데이터는 [src/proposal.tsx](src/proposal.tsx)
